# CANONICAL VALIDATED CONFIGURATION  --  single source of truth
#
# Eight knobs had drifted between inputs_hindcast and the bdyfix/ runs we
# actually scored. That was a process failure, not eight bugs: there was no
# mechanism forcing the shipped deck to match the validated one. This file is
# that mechanism. stage_run.sh's preflight asserts every MUST line against the
# staged deck and refuses to stage a mismatch.
#
# Adding a knob here makes it mandatory. Moving it to EXCEPT makes it a
# deliberate, documented divergence. There is no third option.
#
# MUST <key> <value>       staged deck must set exactly this
# EXCEPT <key> <reason>    deliberate divergence; value not asserted
# DOMAIN <tag> <n_cell>    starts a domain-specific block
#
# Lines before the first DOMAIN apply to every domain. Lines after a DOMAIN line
# apply only when the deck's amr.n_cell matches it. Domain-specific values --
# the anchor binary, prob_lo/prob_hi, grid stretching -- MUST live in a DOMAIN
# block, or the guard that catches drift becomes the thing blocking a legitimate
# domain change.
#
# PROVENANCE (added 2026-07-26). Every knob carries a `prov:` line: what it was
# set for, when, and WHICH CONFIGURATION it was validated against. Three knobs
# this campaign -- moistscal_*, advect_tke, cfl -- turned out to have been set
# on the broken IC and never revisited, and each was rediscovered independently
# at real cost. A value with no stated basis is not validated, it is inherited.
#
#   [BROKEN-IC]  set BEFORE the frame_from_T thermodynamic correction reached
#                the shipped deck (commit 617017b0, 2026-07-26) and NOT
#                re-validated since. The IC it was tuned against had a
#                ~18 hPa pressure error and was superadiabatic in places, so
#                the failure mode it prevents may no longer exist. Treat these
#                as open questions, not as settled configuration.
#
# Provenance lines are comments. They MUST stay on their own line: the parser
# does split(None, 2), so an inline comment would be swallowed into the
# asserted value and every deck would fail against a value nobody wrote.
