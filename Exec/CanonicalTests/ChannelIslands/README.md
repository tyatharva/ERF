# Channel Islands hindcast (single precision)

384 x 192 km @ 1 km, 48 stretched levels to 20 km, NE corner anchored at
(34.5 N, -117.2 W). HindCast init from ERA5 via erftools; Morrison
microphysics, MYNN-EDMF PBL, RRTMGP radiation + NOAHMP land surface for
production (SLM / no radiation for Phase 1).

## Files
- `inputs_hindcast`        -- audited ERF inputs deck (see `[CORRECTED]` notes)
- `Dockerfile`             -- erf-hindcast image: erf-env + gfortran/NetCDF-Fortran
                              (NOAHMP) + erftools + Python geo stack
- `dem_to_erf_terrain.py`  -- GLO-30/SRTM GeoTIFF -> ERF terrain file, in the
                              same LCC projection erftools uses for ERA5
- `patches/rrtmgp-sp-minor-scaling.patch` -- REQUIRED for single-precision
                              RRTMGP (see below)

## RRTMGP single-precision patch (required)

`Submodules/RRTMGP` is a git submodule; its fix cannot be carried by this
repository directly. After `git submodule update --init`, apply:

    git -C Submodules/RRTMGP apply \
        ../../Exec/CanonicalTests/ChannelIslands/patches/rrtmgp-sp-minor-scaling.patch

Root cause: in `gas_optical_depths_minor` the minor-gas scaling was evaluated
left-to-right as `scaling * col_gas_imnr * vmr_fact * dry_fact`; the first
product multiplies two ~1e22-1e24 column amounts and overflows FLT_MAX
(~3.4e38) -> inf -> NaN fluxes. Verified: 36-46%% of optical depths were
non-finite in single precision before the fix; zero after; double precision
results unchanged (regrouping is algebraically identical, and the sibling
`scale_by_complement` branch was already parenthesized this way).
